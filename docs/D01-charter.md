# D01 팀 차터

## 목표

앉은 자리에서 문서를 보다가 일어서서 회의하는 등 자세와 작업이 바뀌어도, 사용자가 모니터 높이를 쉽게 맞출 수 있게 한다.

## 이번 수업 범위

- 웹캠으로 눈높이를 추정하고, 버튼을 누르면 모니터암이 목표 높이로 이동하는 흐름을 정의한다.
- 기존 MediaPipe 웹캠 연동 브라우저 3D 데모를 활용해 동작을 확인한다.
- 이번 제출은 팀 차터, 문제 정의, 요구사항 명세까지다. 실물 제작과 장시간 사용 효과 측정은 후속 범위다.

## 역할

1인 팀으로 문제 정의, 데모 확인, 문서 제출을 맡는다.
