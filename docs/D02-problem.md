# D02 문제 정의

## 누가 어떤 불편을 겪나

앉아서 문서를 보다가 서서 회의하는 사람은 자세가 바뀔 때마다 화면 높이를 다시 맞춰야 할 수 있다. 손으로 화면을 움직이고 다시 자세를 잡아 보는 일이 번거로우면 화면을 그대로 두고 고개를 숙이거나 앞으로 내밀게 된다. 거북목이나 일자목이 신경 쓰이는 사람이 작업 자세를 바꿀 때 겪는 불편에서 출발했다.

## 해결 방향

사용자가 자동 맞춤 버튼을 누르면 웹캠으로 현재 눈높이를 추정한다. 화면 상단을 눈높이에 대해 사용자가 정한 위치로 옮긴다. 앉기·서기 저장 위치는 필요할 때 직접 불러오는 보조 기능으로 둔다.

화면을 손으로 다시 맞추는 빈도와 걸리는 시간은 관찰로 확인할 가설이다. 이번 검증은 화면 위치 조정 동작에 한정한다.
