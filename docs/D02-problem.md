# D02 문제 정의

## 누가 어떤 불편을 겪나

장시간 컴퓨터 앞에서 일하는 사람은 하루 동안 똑바로 앉기, 앞으로 숙이기, 의자에 기대 눕기, 서서 일하기처럼 자세가 계속 바뀐다. 자세가 바뀔 때마다 모니터를 손으로 다시 맞추기 번거로우면 화면을 그대로 두고 일하게 되고, 그 결과 세 가지 문제가 생긴다.

1. 시력 부담: 작업에 집중하면서 상체를 앞으로 기울이면 눈이 화면에 너무 가까워진다.
2. 거북목·일자목 부담: 화면 높이·기울기가 눈과 어긋나면 고개를 숙이거나 앞으로 내밀고 보게 된다.
3. 자세 전환 제약: 기대 눕거나 일어설 때 화면이 따라오지 않으면 편한 자세를 유지하기 어렵다.

## 해결 방향

웹캠으로 사용자의 얼굴·눈 위치를 추적해 화면의 앞뒤·좌우 위치, 높이, 상하 기울기, 좌우 방향을 자동으로 맞춘다. 문서·코드 읽기처럼 세로 화면이 편한 작업에서는 모니터를 가로형과 세로형으로 전환(피벗)할 수 있게 한다. 자동 이동 중에도 정지 버튼과 수동 조작을 항상 우선으로 두고, 앉기·서기 같은 저장 위치 불러오기는 보조 기능으로 제공한다.

## 유사 제품과 이번 범위

유사 제품(예: CyboPal ONE)은 수직 다관절 6축 로봇팔에 27인치 모니터를 달아 얼굴·자세 추적으로 화면 높이·거리·기울기·회전을 맞추며(도달 약 747 mm), 수동 조작과 프리셋을 지원한다. 우리 프로젝트도 같은 수직 다관절 6축(RRRRRR) 구조를 채택해 4가지 작업 자세 대응과 모니터 가로·세로 피벗 전환까지 지원한다. 음성 명령과 손 제스처 같은 부가 입력은 이번 범위에서 뺀다.

자세 변화 빈도, 수동 조정에 드는 시간, 장기적인 시력·목 부담 완화 효과는 관찰과 시험으로 확인할 가설이다. 이번 검증은 시뮬레이션 기준 화면 위치·각도 제어 동작에 한정한다.
