# D03 요구사항 명세

**사용자 요구** → 앉기·숙이기·기대 눕기·서기처럼 자세가 바뀌어도 눈이 화면에 너무 가까워지거나 고개를 내밀지 않고 일하고, 필요할 때 화면을 가로·세로로 돌려 쓰고 싶다.
**시스템 동작** → 웹캠으로 얼굴·눈 위치를 추적해 수직 다관절 6축 모니터암으로 눈–화면 거리, 높이, 기울기를 맞추고, 명령에 따라 가로·세로 피벗을 전환한다.

## 요구사항 표

근거가 없는 숫자는 `(잠정)`으로 적었다.

| ID | 종류 | 요구사항 | 우선 | 근거 | 확인 방법 |
|---|---|---|---|---|---|
| R-01 | 기능(시력) | 눈 중심과 화면 중심 거리를 0.50~0.70 m(50~70 cm) 안에 유지한다. | Must | 고용노동부 VDT 작업관리지침(40 cm 이상), 미국 OSHA 가이드(50~100 cm) 기준; 50~70 cm는 27인치 책상 작업 잠정 목표 | 각 자세에서 눈 중심과 화면 중심 사이 거리를 잰다. |
| R-02 | 기능(목) | 화면 기준 높이(가로형은 상단 모서리, 기대 눕기는 머리 정면 시선선, 세로형은 책상 여유 확보 후 상단 1/3 읽기선)를 목표 높이에서 ±15 mm 이내(잠정)로 맞춘다. | Must | OSHA·VDT 지침(화면 상단은 눈높이 또는 약간 아래); 세로형(61 cm) 책상 여유 고려, ±15 mm 잠정 | 각 자세에서 화면 기준 높이와 목표 높이 차이를 잰다. |
| R-03 | 기능(목) | 화면 정면 법선과 화면 중심→눈 중심 방향 사이 각도 차이를 10° 이내(잠정)로 맞춘다. | Must | 고개를 숙이거나 내밀지 않고 정면 시야를 유지하기 위한 잠정 기준 | 각 자세에서 화면 법선 벡터와 시선 방향 각도 차이를 계산한다. |
| R-04 | 기능(자세) | 똑바로 앉기, 앞으로 숙이기, 의자에 기대 눕기, 서기 4가지 자세에서 R-01~R-03을 모두 만족한다. | Must | D02 대상 작업 자세 4종 | MuJoCo 장면의 4개 자세 키프레임에서 R-01~R-03 통과 여부를 확인한다. |
| R-05 | 성능(자세) | 자세가 바뀐 뒤 4초 이내(잠정)에 목표 위치·각도에 도달한다. | Should | R-11 속도 상한(0.15 m/s)에서 최대 이동 구간(~0.48 m) 이동 시간 고려, 잠정 | 자세 전환 입력 시각부터 R-01~R-03 도달 시각까지 경과 시간을 잰다. |
| R-06 | 기능(피벗) | 버튼·명령으로 모니터를 가로형(0°)과 세로형(90°) 사이에서 전환할 수 있으며, 전환 중·전환 후 책상·벽 충돌 없이 R-10 여유 기준을 유지한다. | Should | D02 가로·세로 화면 전환 요구 | `portrait`(90°) 키프레임과 전환 구간에서 거리·각도·여유·접촉을 확인한다. |
| R-07 | 기능(보조) | 사용자는 자주 쓰는 자세(앉기·서기 등)의 저장 위치를 불러올 수 있다. | Should | D02 보조 기능 | 두 위치를 저장한 뒤 불러오기 입력으로 목표 위치 도달을 확인한다. |
| R-08 | 안전 | 얼굴·눈 위치를 추정할 수 없으면(시야 이탈·가림·신뢰도 미달) 자동 이동을 시작하지 않고 현재 위치를 유지한다. | 안전 | D08 안전 개념 S-05 | 얼굴이 카메라 밖에 있을 때 자동 맞춤을 요청해 위치 변화를 본다. |
| R-09 | 안전 | 이동 중 정지 버튼 입력이나 수동 조작이 들어오면 즉시 멈추고, 새 자동 명령 전까지 위치를 유지한다. 정전·이상 시에도 모니터가 급락하지 않게 지지한다. | 안전 | D08 안전 개념 S-04, S-06 | 이동 중 정지·수동 입력과 전원 차단 조건에서 정지·추락 방지 동작을 확인한다. |
| R-10 | 안전 | 모니터·로봇암 링크와 책상·뒷벽 사이 끼임(책상 여유 50 mm 이상, 뒷벽 여유 50 mm 이상, 잠정 — 피벗 전환 포함)과 사람 쪽 충돌(접촉 0건)을 막는다. | 안전 | D08 안전 개념 S-01, S-02 | 이동 전 구간과 5개 키프레임에서 책상·벽 여유 거리와 접촉 건수를 확인한다. |
| R-11 | 안전 | 이동 중 화면 직선 속도 0.15 m/s 이하, 관절 각속도 0.5 rad/s 이하, 말단 접촉력 80 N 이하 및 관절 토크 상한(어깨 60 N·m, 베이스·팔꿈치 45 N·m, 손목 20 N·m, 모두 잠정)으로 제한한다. | 안전 | D08 안전 개념 S-03 | 시뮬레이션 매 제어 주기 말단 속도·관절 각속도·토크 최대값을 기록해 확인한다. |
| R-12 | 안전(개인정보) | 웹캠 영상 프레임은 메모리에서 눈·얼굴 위치 계산에만 쓰고 즉시 폐기하며, 디스크 저장이나 외부 전송을 하지 않는다. | 안전 | D08 안전 개념 S-08 | 인식·로그 코드에서 영상 파일 쓰기·네트워크 전송이 없는지 점검한다. |

## 범위 밖 (Won't)

- 음성 명령, 손 제스처 인식
- 실물 하드웨어 제작 및 장기 시력·목 부담 개선 효과 검증

4일차부터 구조·배치 확인은 MuJoCo 장면(`scenes/monitor_arm.xml`) 기준으로 진행한다. 기존 MediaPipe 브라우저 3D 데모와는 별개이며, MuJoCo 내 자동 추적 제어 시험 결과는 아직 없다.
