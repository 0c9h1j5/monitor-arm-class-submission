# D03 요구사항 명세

**사용자 요구** → 앉거나 서는 자세가 바뀔 때 화면 높이를 쉽게 맞추고 싶다.
**시스템 동작** → 버튼을 누르면 눈높이를 추정하고, 설정한 높이 차를 적용해 화면을 이동한다.

| 번호 | 요구사항 | 확인 방법 |
|---|---|---|
| R-01 | 자동 맞춤 버튼을 눌렀을 때 화면 상단을 눈높이 기준 목표 높이로 이동한다. | 앉기·서기 두 눈높이 값을 데모에 입력하고, 각 목표와 도달 높이의 차이를 잰다. 잠정 기준은 10mm 이하다. |
| R-02 | 눈높이를 추정할 수 없으면 자동 이동을 시작하지 않는다. | 얼굴이 카메라 화면 밖에 있을 때 자동 맞춤을 요청하고 화면 위치가 유지되는지 확인한다. |
| R-03 | 이동 중 정지 버튼을 누르면 모니터암이 멈춘다. | 이동 중 정지 입력을 주고 새 이동 명령 전까지 위치가 유지되는지 확인한다. |
| R-04 | 사용자는 앉기·서기 저장 위치를 각각 불러올 수 있다. | 서로 다른 두 위치를 저장하고 각 설정을 불러와 맞는 높이로 가는지 확인한다. |

R-01의 눈높이 입력은 암의 이동을 확인하는 시험이다. 웹캠의 눈높이 추정은 실제로 앉고 서면서 별도로 확인한다. 기존 브라우저 3D 데모를 활용할 계획이며, 이 제출본에 대한 시험 결과는 아직 없다.
